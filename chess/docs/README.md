# Chess Documentation Folder

## Overview

This folder contains the core documentation for the chess project, focused on the official FIDE Laws of Chess, system architecture, and printable rules. It is intended for chess players, arbiters, organizers, and anyone needing formal, authoritative references for chess rules and system structure. All documentation in this folder is self-contained and does not reference or depend on files outside `chess/docs/`.

## Folder Structure

- `architecture.md` — Describes the structure and organization of the chess project, including directory purposes, navigation principles, and best practices for documentation and context engineering.
- `rules.pdf` — A printable, official version of the FIDE Laws of Chess for easy sharing and offline reference.

## Contents

### File List

- `architecture.md`: Project organization and context engineering guide, covering:
  - Directory structure and navigation
  - Organizational principles (hub-and-spoke navigation, single source of truth)
  - Best practices for documentation and maintenance
- `rules.pdf`: Complete, printable version of the FIDE Laws of Chess.

### No Subdirectories

This folder does not contain any subdirectories.

## Usage

- **Reference**: Use `architecture.md` to understand the structure and documentation principles of the chess project.
- **Printing/Sharing**: Use `rules.pdf` for a formatted, printable copy of the official chess rules.
- **Documentation**: This folder serves as the canonical source for project meta-documentation and printable rules.
