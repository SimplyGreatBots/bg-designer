# Chess Mechanics Folder

## Overview

This folder provides a comprehensive reference to the core mechanics that define the game of chess, as formalized in the FIDE Laws of Chess. It is intended for chess players, arbiters, system designers, and researchers who require a clear, structured summary of chess's fundamental gameplay mechanisms. The documentation here is self-contained and does not reference files outside this folder.

## Folder Structure

- `mechanics.md` — The primary documentation file, detailing each core chess mechanic, its description, mapping to BoardGameGeek (BGG) taxonomy, and justification from the official rules.

## Contents

### File List

- `mechanics.md`: Contains detailed descriptions of chess mechanics, including:
  - Turn-based play
  - Grid and pattern movement
  - Static capture
  - Endgame conditions (checkmate, stalemate, resignation, draw)
  - Special moves (castling, en passant, promotion)
  - Touch-move rule
  - Chess clock/time controls
  - Chess960/variable setup
  - BGG mappings and justifications

### No Subdirectories

This folder does not contain any subdirectories.

## Usage

- **Reference**: Use `mechanics.md` to understand or explain the fundamental mechanics of chess, or to map chess rules to general game mechanic taxonomies.
- **System Design**: Useful for developers or researchers modeling chess or chess-like games.
- **Documentation**: Serves as a canonical source for chess mechanics within this project.

## Scope & Boundaries

- All documentation in this folder is self-contained and does not reference or depend on files outside `chess/mechanics/`.
- For official rules, see the documentation in `chess/docs/` (not referenced here per folder scope).
- This folder is limited to the mechanics of chess and does not cover strategy, tactics, or implementation details.

## Disclaimer

This README and all documentation in this folder are limited in scope to the files present within `chess/mechanics/`. No external files or resources are referenced. For broader context, consult the appropriate documentation in other folders.
