# Pokémon TCG Rules Folder

## Overview

This folder contains the official rules and definitions for the Pokémon Trading Card Game (TCG). It is intended as a reference for players, judges, and organizers who need authoritative information on gameplay mechanics, terminology, and card interactions. All content in this folder is focused exclusively on the rules of the Pokémon TCG and does not cover other aspects of the game such as card lists, deck construction, or tournament organization.

## Folder Structure

- `rules.md` — The comprehensive rulebook for the Pokémon TCG, including definitions, gameplay steps, card types, and special mechanics.

## Scope and Boundaries

- **Scope:** This folder documents only the rules and gameplay definitions for the Pokémon TCG. It does not include card databases, decklists, or strategy guides.
- **Boundaries:** All files and information in this README pertain solely to the contents of the `pokemon-tcg/rules` folder. No references are made to files outside this folder.

## Prerequisites

- Basic familiarity with the Pokémon Trading Card Game is helpful but not required.
- No software or external dependencies are needed to use the files in this folder.

## Usage Instructions

1. **Reading the Rules:**
   - Open `rules.md` to access the full rulebook. The file is written in markdown for easy reading and searching.
   - Use the table of contents at the top of `rules.md` (if present) to navigate to specific sections.
2. **Reference:**
   - Use the definitions and explanations in `rules.md` to clarify gameplay situations, card effects, or terminology during play.
3. **Printing:**
   - You may print `rules.md` for offline reference or tournament use.

## File Descriptions

- **rules.md**
  - Contains:
    - Glossary of game terms (e.g., "attach", "attack", "Bench", etc.)
    - Detailed explanations of card types (Pokémon, Trainer, Energy, etc.)
    - Special mechanics (e.g., VSTAR Power, GX attack, Mega Evolution)
    - Game phases and steps
    - Credits and acknowledgments
    - Contact information for official support
